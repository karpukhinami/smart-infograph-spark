# Видимость границ секущих плоскостей

- Использовать для проверки видимости ту же проекцию пирамиды, которой рисуется чертёж.
- Сохранить пунктир только для действительно скрытых частей границ и для линий пересечения плоскостей.
- Проверить отмеченную сцену и несколько ракурсов, не меняя геометрию параллелепипеда.
