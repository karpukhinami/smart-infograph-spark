# Исправление глубины и пересечений плоскостей во вкладке «Пространство»

## Что обнаружено

- Проекция точек плоскостей и расчёт их глубины расходятся: для параллелепипеда и пирамиды используются разные ветки, а два режима глубины не всегда соответствуют реально нарисованному ракурсу.
- После расчёта глубина дополнительно искусственно меняется попарной функцией `reconcileTwoPlaneFragmentsByScreenSide`. Она принудительно переворачивает «победителя» на одной стороне пересечения и не может дать согласованный порядок для трёх плоскостей: поправки одной пары портят уже рассчитанную другую пару.
- Фрагменты сортируются только по глубине барицентра. Этого недостаточно для перекрывающихся наклонных многоугольников: сравнивать нужно в общей экранной области двух фрагментов.
- Последовательное разбиение по полупространствам сохраняет точки на линии разреза в обеих частях без нормализации. При двух и особенно трёх плоскостях накапливаются повторные вершины и почти нулевые фрагменты, которые дают швы, лишние линии и случайные заливки.
- Линия пересечения уже предусмотрена, но использует отдельный короткий пунктир и смешанный цвет двух плоскостей; её построение зависит от проблемного клиппинга. Это не соответствует требованию «как остальной пунктир, цвет одной плоскости».
- В клиппинге пирамиды знак внутреннего полупространства берётся по центру самой грани, то есть практически по нулю. Из-за этого диапазон линии пересечения может вычисляться неверно или исчезать.

## Изменения

### 1. Единая модель проекции и глубины

- Сделать `projectWorldDisplay` единственным источником экранных координат и глубины для заливок, контуров, точек и линий пересечения.
- Глубину получать из той же проекции и того же текущего `yaw`, которыми реально построен чертёж; убрать отдельные несовместимые трактовки «глаз» и «вертикальная плоскость» из сортировки заливок.
- Оставить чтение старого поля `planeFillDepthMode` из JSON для совместимости, но больше не позволять ему менять визуальную геометрию. В панели оставить один согласованный режим без выбора между противоречащими методами.

### 2. Устойчивое разбиение сечений

- После каждого разреза удалять соседние дубли, замыкание-дубликат и коллинеарные точки.
- Отбрасывать вырожденные и почти нулевые фрагменты по площади в локальном базисе исходной плоскости.
- Разрезать плоскость только когда конечный отрезок пересечения реально проходит через оба сечения внутри тела, а не по бесконечной плоскости вне общей области.
- Исправить клиппинг пирамиды: определять внутреннюю сторону каждой грани по центру объёма, а не по точке на самой грани.

### 3. Корректный порядок заливок

- Удалить искусственное изменение числовой глубины для каждой пары плоскостей.
- Для экранно перекрывающихся фрагментов строить отношение «дальний → ближний» по глубине в общей области перекрытия, используя значения той же проекции в вершинах/треугольниках.
- Выполнять устойчивую топологическую сортировку фрагментов. После разбиения всеми реальными линиями пересечения порядок каждой пары на одном фрагменте должен быть постоянным; это исключит ситуацию, когда обе половины одной плоскости ошибочно оказываются впереди обеих половин другой.
- Добавить детерминированный запасной порядок только для касаний и численно равных глубин, без изменения физической глубины.

### 4. Пунктир пересечения

- Рисовать один отрезок на каждую реально пересекающуюся пару поверх заливок.
- Использовать общий шаблон скрытого пунктира чертежа и цвет одной из плоскостей (детерминированно — первой в порядке объектов), без смешивания цветов.
- Не рисовать технические границы, возникшие только из-за разбиения заливки.

### 5. Проверки

- Добавить геометрические проверки для двух плоскостей на нескольких углах поворота: линия существует, обе плоскости меняются местами по разные стороны пересечения, порядок не зависит от порядка создания объектов.
- Добавить сценарии трёх попарно пересекающихся плоскостей: нет дублей/нулевых фрагментов, технических рёбер и циклического порядка.
- Проверить отдельно параллелепипед и пирамиду, включая поворот через 0°, 90°, 180° и промежуточные углы.
- В предпросмотре проверить включение «Рассчитать глубину», видимость и стиль пунктира, отсутствие швов и правильную яркость ближней плоскости.
