# Производные точки и прямые сечений

## Что изменю
- Добавлю в создание точки отдельный способ «Из построений». Он покажет доступные результаты геометрических построений формулами, без заранее назначенных имён:
  - пересечение секущей плоскости с ребром фигуры;
  - две граничные точки линии пересечения двух плоскостей.
- При выборе результата «пересечение двух плоскостей» одной командой создам сразу обе его граничные точки. Они получат обычные свободные буквенные имена и появятся в списке точек только после этого действия.
- Добавлю в создание прямой способ «Из построений» со списком существующих пересечений пар построенных плоскостей. При выборе создам прямую пересечения и автоматически материализую обе её граничные точки.
- Производные точки и прямые будут хранить формулу происхождения, а не копию координат. При перестроении исходной плоскости они пересчитаются; одинаковое построение повторно не продублируется.
- В списках кандидатов не показывать невозможные результаты: параллельные плоскости, пересечения вне тела и плоскости, не пересекающие выбранное ребро.
- Оставить производные объекты скрытыми от основной панели до явного выбора пользователем. После выбора это обычные редактируемые объекты сцены, доступные для последующих построений.
- Добавить рядом с «Рассчитать глубину» независимый переключатель «Показывать линии пересечения». По умолчанию он выключен. Он управляет только автоматическим пунктиром на рисунке и никогда не создаёт точки или прямые.
- Сохранить переключатель в JSON сцены; для старых сцен считать его выключенным.

## Поведение зависимостей
- Точка плоскость–ребро зависит от конкретной плоскости и конкретного ребра.
- Две конечные точки пересечения плоскостей зависят от конкретной пары плоскостей и границ тела; их порядок фиксируется детерминированно.
- Прямая пересечения зависит от той же пары плоскостей и использует созданные вместе с ней две точки как свои границы на теле.
- При изменении исходных объектов производные объекты перестраиваются. При невозможности построения они сохраняются в панели с понятной ошибкой, а не получают старые координаты и не связываются с посторонними плоскостями.

## Интерфейс
- В карточке создания точки: способ «Из построений» → один список формул доступных результатов → «Построить».
- Формулы будут человекочитаемыми, например `α ∩ AB` и `α ∩ β → две граничные точки`, без временных имён объектов.
- В карточке создания прямой: способ «Из построений» → список `α ∩ β` → тип линии → «Построить».
- Уже материализованные варианты помечать как добавленные или исключать из списка, чтобы не создавать дубликаты.

## Проверка
- Проверить точки пересечения плоскости со всеми рёбрами пирамиды и параллелепипеда.
- Проверить создание обеих точек и прямой для пары плоскостей, повторный выбор и пересчёт после изменения исходной плоскости.
- Проверить, что выключенный переключатель скрывает только автоматический пунктир, не скрывая созданную пользователем прямую и не удаляя объекты.
- Проверить сохранение и загрузку сцены, ошибки зависимостей и типы проекта.
