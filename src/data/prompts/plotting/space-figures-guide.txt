МНОГОГРАННИКИ (shapeKind)

Инструмент строит только три типа тел. Выбери один shapeKind и заполни baseVerticesInput — буквы латиницы/кириллицы, порядок важен.

1) parallelepiped — параллелепипед
   baseVerticesInput: ровно 4 буквы нижнего основания по обходу, например "A, B, C, D".
   Верхние вершины создаются автоматически с индексом 1 (A₁, B₁, …).
   figureConstraints (задаёт только модель):
   - rectangular: boolean — true: ребро AA₁ на чертеже вертикально («прямоугольный»); false: наклонное ребро высоты.
   Не задавай equilateral, badAngleDeg — приложение подставит само.

2) pyramid — пирамида
   baseVerticesInput: первая буква — вершина S, далее минимум 3 буквы основания по порядку, например "S, A, B, C".
   figureConstraints:
   - apexOnCenter: boolean — true: вершина на чертеже над центром основания; false: над первой буквой основания (вторая буква в строке ввода).

3) prism — призма
   baseVerticesInput: минимум 3 буквы нижнего основания, без отдельной вершины, например "A, B, C, D".
   Верхнее основание — те же буквы с индексом 1.
   figureConstraints:
   - straight: boolean — false: как «вершина над центром» у пирамиды (прямая призма на чертеже); true: как «вершина над первой вершиной основания».

ОБЩЕЕ
- После импорта фигура считается построенной; не дублируй встроенные вершины в points.
- Ссылайся на вершины тела по label (A, B, S, A₁ …), не по внутренним id.
- Поворот чертежа: только view.yaw (градусы, 0…360), если в условии нужен другой ракурс. Не задавай fitScale, depthLength, showRotationEllipse, showViewConvergenceRays, planeFillByDepth и прочие технические поля view.
