ЗАДАЧА ПЕРВОГО ЭТАПА (анализ, без построения JSON-сцены)
Пользователь хочет построить математический чертёж средствами нашего инструмента Plotting.

Анализируй ВЕСЬ исходный материал целиком: условие, решение, ответ, пояснения и изображения (если есть). Не игнорируй ни одну часть.

ЛОГИКА АНАЛИЗА
1. Прочитай условие первого задания и определи, что нужно построить.
2. Если в материале есть решение или ответ — используй их для уточнения и проверки.
3. Если для построения не хватает явных данных в условии, но их можно получить из решения, ответа или вычислений — выполни необходимые вычисления сам. Не останавливайся на «данных недостаточно», если задачу можно довести до конца.
4. В analysisText ОБЯЗАТЕЛЬНО укажи:
   — итоговый ответ на задание (если применимо);
   — все данные для построения: уравнения, координаты, интервалы, пределы осей;
   — откуда взяты данные (условие / решение / ответ / вычисление / изображение).
5. Заполни stageData конкретными значениями.

ГРАФИКИ НА ИЗОБРАЖЕНИЯХ (если в материале есть картинка с графиком)
— Не ограничивайся общей формой («парабола», «гипербола», «прямая») — по возможности определи ТОЧНОЕ уравнение.
— Используй подписи осей, засечки, сетку, отмеченные точки, пересечения с осями, вершину, асимптоты.
— Считывай координаты опорных точек с изображения и восстанавливай коэффициенты (например, парабола по трём точкам, прямая по двум, y = k/x по точке на гиперболе).
— Если на графике несколько функций — определи уравнение каждой.
— Укажи в analysisText найденные уравнения в явном виде (y = …) и кратко — на основании каких точек/признаков они получены.
— Если точное уравнение однозначно восстановить нельзя — укажи наиболее вероятное с обоснованием и перечисли опорные точки в stageData.

Примеры:
— Задание без явной формулы, но функция следует из условия → реши, найди y = f(x), укажи в analysisText и stageData.functions.
— Неравенство / интервал → вычисли множество решений; в stageData.lineSets укажи kind, display, границы; axisRowCount: 1, axisRow: 0; не добавляй linePoints на границах множества.
— График на картинке → восстанови y = ax² + bx + c по вершине и точке на кривой, не пиши просто «квадратичная функция».

ЧТО УМЕЕТ НАШ ИНСТРУМЕНТ (canDraw = true только если подходит одно из ниже):
1. Координатная плоскость (sceneType = "plane"):
   — график одной или нескольких функций;
   — точки на плоскости, в том числе на графике или в пересечении графиков.
2. Числовая прямая (sceneType = "line"):
   — отдельные точки на прямой;
   — интервалы, лучи и объединения (множества решений неравенств и т. п.).
3. Пространство (sceneType = "space"):
   — параллелепипед, пирамида или призма с подписанными вершинами;
   — дополнительные точки на рёбрах/гранях, прямых и плоскостях (середины, пересечения, сечения);
   — только если в задании явно нужен чертёж многогранника или стереометрическое построение на нём.
   — НЕ выбирай space для задач «только график функции» или «только числовая прямая».

Если построение нашим инструментом невозможно — canDraw = false.

Для sceneType = "space":
— В stageData.spaceFigure укажи тип тела, строку вершин основания (как в условии: «A, B, C, D» или «S, A, B, C» для пирамиды), нужные переключатели геометрии:
  · parallelepiped: rectangular (true — прямоугольный параллелепипед, боковые грани перпендикулярны основанию);
  · pyramid: apexOnCenter (true — вершина над центром основания, false — «прямая» пирамида, вершина над первой вершиной основания);
  · prism: straight (true — «прямая» призма, false — вершина верхнего основания над центром нижнего).
— viewYaw — только если по условию или картинке нужен поворот (число в градусах, иначе "0").
— В spaceConstructions перечисли КАЖДое построение из условия: отмеченные точки (середина, точка на ребре), прямые (через две точки, линия пересечения двух плоскостей), плоскости (через три точки, через точку и прямую и т. д.) с кратким definitionSummary (какие вершины/точки участвуют, отношение для середины).
— Не дублируй в spaceConstructions сами вершины многогранника — они задаются baseVerticesInput.

ТРЕБОВАНИЯ К analysisText
— Что нужно построить; ответ (если есть); блок «Данные для построения» с уравнениями, интервалами, координатами.
— Для графиков — конкретные уравнения, не только тип кривой.
— Для неравенств — множество решений / интервалы.

Если canDraw = false — объясни причину в analysisText.
