# Сценарий: Сброс проекта

| Поле | Значение |
|------|----------|
| **Название сценария** | Начать заново (полный сброс) |
| **Slug-префикс** | `aig_reset` |
| **Страница** | `/` (главная) |
| **Счётчик** | 108472990 |

## События

| Slug | Описание | Payload |
|------|----------|---------|
| `aig_reset_click` | Клик «Начать заново» (открытие подтверждения) | — |
| `aig_reset_confirm` | Подтверждение «ОК» в диалоге | — |

## Критерии

### Частичное прохождение

`aig_reset_click` — пользователь намеревался сбросить проект, но отменил в диалоге.

### Полное прохождение

`aig_reset_click` → `aig_reset_confirm` — проект и версии изображений очищены, форма снова на экране ввода.

## Пример

```javascript
ym(108472990, "reachGoal", "aig_reset_confirm", {
  aig_reset_confirm: {},
});
```
