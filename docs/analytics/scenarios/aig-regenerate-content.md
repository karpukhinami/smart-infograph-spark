# Сценарий: Перегенерация контента

| Поле | Значение |
|------|----------|
| **Название сценария** | Перегенерация текстового контента |
| **Slug-префикс** | `aig_regen_content` |
| **Страница** | `/` (главная), экран результатов |
| **Счётчик** | 108472990 |

## События

| Slug | Описание | Payload |
|------|----------|---------|
| `aig_regen_content_click` | Клик «Перегенерировать контент» (открытие диалога) | — |
| `aig_regen_content_success` | Контент успешно обновлён | `entity_count`, `has_extra_instructions` |

## Критерии

### Частичное прохождение

Отправлено `aig_regen_content_click` — пользователь начал перегенерацию контента.

### Полное прохождение

Оба события в одной попытке: клик → подтверждение в диалоге → успешный ответ LLM (`aig_regen_content_success`).

## Пример

```javascript
ym(108472990, "reachGoal", "aig_regen_content_success", {
  aig_regen_content_success: {
    entity_count: 5,
    has_extra_instructions: true,
  },
});
```
